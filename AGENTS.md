# AI Execution Rules

* Follow the current prompt literally and only.
* Do not infer, invent, or implement requirements that are not explicitly stated.
* Do not modify unrelated files or features.
* Do not add dependencies unless required by the current task.
* Do not change existing architecture or tooling unless explicitly requested.
* Inspect existing code before making changes.
* If information is missing or ambiguous, do not guess; report it.
* Never claim code, tests, builds, or behavior were verified unless actually verified.
* Keep changes minimal and scoped to the current task.

## Plan Mode

* Analyze and propose only.
* Do not implement.
* Do not create, modify, or delete files.
